# play2learn# 🎮 Play2Learn – Gamify Your Learning!

Welcome to **Play2Learn**, an interactive and fun way to test your knowledge while playing classic games! This project blends education and entertainment with quizzes embedded inside popular games like **Tic-Tac-Toe** and **Snake**.

> 🏷️ Labels: `GSoC Innovators Club` · `Summer of CodeFest '25`

---

## 🚀 Features

- 🎲 **Tic-Tac-Toe Quiz Game**: Win each square by answering a quiz question correctly!
- 🐍 **Snake Quiz Game**: Each food item leads to a quiz—get it right to grow the snake!
- 🧠 Topics covered:
  - Quantum Numbers
  - Newton's Laws of Motion
- 🎨 Unified, modern design using external CSS and JS for both games
